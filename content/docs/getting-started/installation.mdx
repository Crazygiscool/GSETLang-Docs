title: Installation

GSET is version **3.3.2**. It is a **single static Rust binary** with no runtime dependencies of its own — you only install a target runtime to *execute* transpiled output.

## Requirements

- To **run** GSET output today, install the target runtime you want to execute: the **Go** backend is the only one implemented so far (Python, JavaScript, Java, and Ruby targets land with M2).
- To **build** from source: Rust from `rust-toolchain.toml` (currently **1.98.1**).

## One-liner install script

```bash
curl -fsSL https://raw.githubusercontent.com/Crazygiscool/GSETLang/main/install.sh | bash
```

The installer downloads the matching release asset for your OS and architecture, installs the binary to `~/.local/bin/gset`, and adds `~/.local/bin` to your `PATH`. Pass `--dir <path>` to install elsewhere:

```bash
curl -fsSL https://raw.githubusercontent.com/Crazygiscool/GSETLang/main/install.sh | bash -s -- --dir ~/bin
```

On Windows use the PowerShell installer:

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Crazygiscool/GSETLang/main/install.ps1 | iex"
```

Verify:

```bash
gset version
```

## Package managers

| Package | Install |
|---------|---------|
| Homebrew | `brew install crazygiscool/gset/gset` |
| Arch Linux (AUR) | `gset` — `paru -S gset` / `yay -S gset` / `makepkg -si` |
| Debian / Ubuntu | `sudo dpkg -i gset-3.3.2-amd64.deb` (from releases) |
| Windows (winget) | `winget install GSETLang.GSET` |
| Windows (Chocolatey) | `choco install gset` |

## Pre-built binaries

Download the latest release from [GitHub Releases](https://github.com/Crazygiscool/GSETLang/releases). Every release ships:

- `gset-linux-amd64.tar.gz`, `gset-linux-arm64.tar.gz`, `gset-3.3.2-amd64.deb`
- `gset-darwin-amd64.tar.gz`, `gset-darwin-arm64.tar.gz`
- `gset-windows-amd64.zip`
- `gset-3.3.2-windows-amd64-setup.exe` (NSIS installer) and
  `gset-3.3.2-windows-amd64.msi` (x64 MSI installer)

The NSIS installer lets you choose between installing for all users or just
the current user. The MSI installs per-machine and requires administrator
privileges.

## Build from source

```bash
git clone https://github.com/Crazygiscool/GSETLang.git
cd GSETLang
cargo build --release --workspace
```

The build emits `target/release/gset` (the binary is named `gset`). The workspace toolchain is pinned in `rust-toolchain.toml`.

| Target | Command GSET shells out to | Status |
|--------|----------------------------|--------|
| Go | `go run` | <span className="badge implemented">Implemented</span> |

| JavaScript | `node` | <span className="badge planned">Planned (M2)</span> |

| Ruby | `ruby` | <span className="badge planned">Planned (M2)</span> |

If a toolchain is missing, `gset run` fails with a clear execution error — install the runtime and try again.
