Requirements: Rust from `rust-toolchain.toml` (**1.98.1**). The workspace toolchain is pinned.

## Build

```bash
cargo build --workspace          # debug
cargo build --release --workspace
```

The binary is `target/release/gset` — the installed name is `gset`, not `gset-cli`, and packaging preserves it.

## The full CI suite

Every check must pass; CI runs exactly these:

```bash
cargo build --workspace --all-targets
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
cargo deny check
```

`cargo-audit` is deliberately not used — `cargo deny check advisories` reads the same RustSec advisory database.

## The M1 gate

```bash
cargo run -p gset-cli -- transpile tests/corpus/py/fib.py --to go -o /tmp/fib.go
gofmt -e /tmp/fib.go        # clean
go vet /tmp/fib.go          # clean
```

This is the milestone gate that proves the cross-language pipeline end to end.

## Grammars are features

The `python` frontend is behind a Cargo feature. Verify feature-gating with:

```bash
cargo build --no-default-features          # no grammar linked
```

## Smoke test after a change

```bash
cargo run -p gset-cli -- transpile tests/corpus/py/fib.py -t go
cargo run -p gset-cli -- run tests/corpus/py/fib.py -t go     # 55
```

`GSET_DEBUG=1` gives verbose logs to stderr.
