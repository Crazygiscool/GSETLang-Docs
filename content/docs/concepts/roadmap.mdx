This is the forward plan for the Rust rewrite, ordered by the milestones in the engineering plan (`docs/RUST_REWRITE_PLAN.md` in the repo). It replaces the Go-era roadmap entirely.

## Done

| Milestone | What shipped |
|-----------|--------------|
| **M0** | Baseline & scaffolding: pinned toolchain, workspace, Go startup baseline, defect fixtures, CI |
| **M1** | Pipeline proof: Python → IR → Go. IR, semantic pass, CLI (`transpile`/`run`/`version`), and the gate: emitted `fib.go` passes `gofmt` and `go vet`. Startup is ~1.86 ms median — faster than the Go baseline. |

## In progress — M2

- JavaScript/TypeScript frontend (shared IR lowering path).
- The remaining four backends: Python, JavaScript, Java, Ruby.
- The **acceptance criterion** that mechanises correctness: every corpus case must pass the target's own syntax checker (`gofmt`/`go vet`, `python -m py_compile`, `node --check`, `javac`, `ruby -c`), gated on toolchain presence in CI.
- Semantic round-trip property test: `IR → Python → IR` equivalence under normalisation.

## Next

| Milestone | Scope |
|-----------|-------|
| **M3** | Frontend breadth: Go, Java, Ruby, then C/C++ and Rust frontends |
| **M4** | Local project graph: multi-file/multi-directory, search roots, package-qualified imports, cycle detection, parallel lowering, content-hash caching |
| **M5** | Ecosystem dependency resolution: pip, npm, Cargo, Maven, Go modules — lockfile-first, with an honest `LocalPath / LockedRemote / Sdk / OpaqueForeign` boundary |
| **M6** | Cutover: rewrite CI and packaging for Rust, preserve release asset names and the one-liner install, rewrite docs, delete the Go tree |

## Verification bar

Every roadmap item ships against the same bar:

- `cargo build --workspace --all-targets`, `cargo test --workspace`, `cargo clippy -D warnings`, `cargo fmt --check`, `cargo deny check` all green.
- Every claimed example **actually runs** (transpile + target syntax check).
- Startup is benchmark-gated: a regression in `gset version` latency fails the build.
