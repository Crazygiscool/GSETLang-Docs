The Java backend is not implemented yet — `gset transpile file.py -t java` currently errors with `no backend for target \`java\`; supported: go`.

## The planned model

The Go-era backend followed a single-public-class model, and the rewrite keeps the shape:

```java
public class Main {
    public static void main(String[] args) {
        var name = "World";
        System.out.println("Hello, " + name);
    }
}
```

## Why Java is a stress test

Java is the hardest of the five targets for dynamic input: untyped code cannot compile. That is exactly why it is part of the M2 gate — `javac` is the strictest checker on the list, and `[]interface{}{}` into Java is one of the recorded defect classes the rewrite eliminates.

## Runtime

Requires both `javac` and `java` on `PATH` to run emitted output.
