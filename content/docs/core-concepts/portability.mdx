Every page in this guide claims a level of support. This page is the legend.

## The badge legend

| Badge | Meaning |
|-------|---------|
| <span className="badge implemented">Implemented</span> | The feature exists in the current codebase and its examples were run end-to-end. |
| <span className="badge planned">Planned</span> | Designed in the engineering plan (`docs/RUST_REWRITE_PLAN.md`) but **not implemented yet**. Running it today produces an error like `no backend for target \`python\``, never wrong output. |

"Implemented" always means *implemented per the caveats printed on that page*.

## What is portable today

One frontend, one backend, end to end:

| Direction | Status |
|-----------|--------|
| Python → Go | <span className="badge implemented">Implemented</span> |
| Python → Python / JS / Java / Ruby | <span className="badge planned">Planned (M2)</span> |
| JS / TS → any backend | <span className="badge planned">Planned (M2)</span> |
| Go / Java / Ruby / Rust / C frontends | <span className="badge planned">Planned (M3)</span> |

## The verified example

```python
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(10))
```

```bash
$ gset run tests/corpus/py/fib.py -t go
55
```

This is the M1 milestone gate: emitted output passes `gofmt` and `go vet`.

## What "portable" will mean once M2 lands

When all five backends exist, the acceptance criterion is:

> For every corpus case, generated output must pass the target language's own syntax checker — `gofmt`/`go vet`, `python -m py_compile`, `node --check`, `javac`, `ruby -c` — gated on toolchain presence in CI.

That is the single highest-value mechanism in the rewrite: it converts "did we emit valid output" from a judgement call into an automated check.

## Verification strategy

- **Golden files** per frontend × backend pair in `tests/golden/`.
- **Target-syntax-check harness** — the gate above.
- **Semantic round-trip property test** — emit Python, re-parse it, and assert the re-parsed IR matches the original under normalisation.
- **Benchmarks as gates** — any change regressing startup or throughput fails the build.

The Go-era claim of "five working backends with per-target quirks" is gone; the rewrite replaced quiet, quirky output with typed errors until a backend actually exists.
